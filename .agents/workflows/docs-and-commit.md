# Docs & Commit Workflow

1. **Analizar cambios**: Identificar archivos modificados y resumir conceptos teóricos o dudas resueltas en la sesión.
2. **Actualizar Log**: Crear o editar `10-docker/docs/daily-logs/YYYY-MM-DD.md` usando la plantilla. Escribir objetivos, notas y siguientes pasos en **español**.
3. **Commit**: Usar la skill [commit](file:///D:/proyectos/proyectos-de-practica/jscamp/.agents/skills/commit/SKILL.md) para generar el mensaje en **español**.
